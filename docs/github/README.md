# GitHub Documentation Index

This directory contains documentation related to GitHub-specific automations and policies.

- [SECURITY-AUTOMATION.md](SECURITY-AUTOMATION.md): OpenSSF Scorecard, CodeQL, Dependency Review, the dependency audit, and workflow hardening.
- [QUALITY-AUTOMATION.md](QUALITY-AUTOMATION.md): Coverage thresholds, mutation testing, SonarCloud, Codecov, and the automated CI summary.

For the security *policy* — how to report a vulnerability, which versions are
supported — see [SECURITY.md](../../SECURITY.md) at the repository root. For
what the worker process itself is permitted to do, see
[docs/security.md](../security.md).
